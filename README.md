# Plantilla Maestra Agnóstica guiada por Agentes AI

Bienvenido a la plantilla base para desarrollo de software guiado por agentes autónomos de IA.

## 🚀 Cómo Iniciar un Nuevo Proyecto

1. Clona o copia esta carpeta para tu nuevo proyecto:
   ```bash
   cp -r //agentic-app-template /home/yariel/mi-nuevo-proyecto
   ```
2. Abre la nueva carpeta en tu editor, interfaz de Antigravity, Claude code, opencode
3. Escribe en el chat: **"Inicia el proyecto"**.
4. Responde las preguntas del **Agente 0 (Product Owner)** sobre la idea, el stack y los roles.
5. El sistema autogenerará el contexto, el stack y el backlog, quedando listo para comenzar la primera funcionalidad.

---

## 🏛️ Pipeline de Agentes
1. **Agente 0:** Product Owner (Entrevista & Contexto).
2. **Agente 1:** Arquitecto + UX (Diseño de API, BD y Mockup en Imagen HD).
3. **🛑 Punto de Control:** Revisión y Aprobación del usuario.
4. **Agente 2:** TDD Tester (Pruebas Unitarias/Integración RED ❌).
5. **Agente 3:** Developer Implementador (Código Angular + Backend + Self-Healing GREEN ✅).
6. **Agente 4:** QA, Seguridad & Documentación (Build limpio + Swagger + Backlog).
